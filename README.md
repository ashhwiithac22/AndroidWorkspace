## 📋 EXPERIMENT 2: ANDROID SERVICES IMPLEMENTATION
### 🎯 AIM
To develop an Android application implementing four essential Android Services for a travel agency app.

### ✨ FEATURES
- 📍 Location Service - Simulates location tracking and displays nearby destinations
- 🔔 Notification Service - Sends travel offers and promotional notifications
- 🎵 Media Service - Plays travel audio guides in the background
- 📍 Geofencing Service - Alerts users when near famous landmarks

### 🛠️ TECHNOLOGIES USED
- Android Services API
- Notification Channels
- MediaPlayer API
- Material Design Cards

### 🚀 SERVICES IMPLEMENTATION
1. Location Service
- Runs as foreground service
- Cycles through 8 destinations every 8 seconds
- Shows notification with nearby places

2. Notification Service
- Creates notification channels
- Sends notifications


3. Media Service
- Uses MediaPlayer for audio playback
- Background audio with foreground notification
- Start/Stop controls

4. Geofencing Service
- Simulates geofencing alerts
- Shows coordinates and radius
- Automatic termination after 5 alerts

### 📊 OUTPUT
- Services run independently in background
- Proper permission handling
- User control with Start/Stop buttons
- Professional Material Design UI

## 📱Experiment 4 - Calculator App
### 🎯 Aim
To create a simple calculator application that performs basic arithmetic operations (addition, subtraction, multiplication, and division) using Android Studio.

### ✨ Features
- Addition, Subtraction of two numbers, Multiplication, Division
- Input validation
- Clean user interface

### 🛠️ Implementation
- UI Design: Two EditText fields for input, four operation buttons, and TextView for result display
- Java Logic: Click listeners for each button to perform operations
- Validation: Checks for empty inputs and division by zero
- Display: Shows formatted results with error messages when needed

### 📁 Files Created
- MainActivity.java - Contains calculator logic
- activity_main.xml - Layout design with buttons and fields
- AndroidManifest.xml - App configuration

### Output
A fully functional calculator app that performs all four basic arithmetic operations with a clean Material Design interface.
